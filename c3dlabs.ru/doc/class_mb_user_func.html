Получить область определения функции.

Получить область определения функции для параметра с индексом ind. Метод вырезает из заданной области определения участки, где функция не определена.

Аргументы
[in,out]dr- Инициализируется некоторым начальным диапазоном. На выходе - пересечение этого диапазона с реальной областью определения функции.
[in]ind- Индекс переменной, для которой ищется область определения.
[in]stopOnBreak- Остановить поиск если найден разрыв.
Возвращает
Возвращает false если область определения найти не удалось.
