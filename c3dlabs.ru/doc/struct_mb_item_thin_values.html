Подробное описание

Расширенный индекс идентификации объекта.

Расширенный индекс содержит имя, номер в теле и контрольную точку и служит для поиска объекта (например, грани а теле для построения тонкой стенки). Поиск объекта производится по имени, в случае неудачи - по номеру, и проверяется по контрольной точке.
