Подробное описание

Параметры создания срединной оболочки между выбранными гранями тела.

Параметры создания срединной оболочки между выбранными гранями тела. Выбранные грани должны быть эквидистантны по отношению друг к другу. Грани должны принадлежать одному и тому же телу.

Перечисления

◆ FilletType

enum MedianShellValues::FilletType

Тип расчета радиуса скругления между гранями срединной оболочки.

Флаг можно установить через вызов MedianShellValues::SetType().

Элементы перечислений
tf_none 

Не определено.

tf_internal 

По внутренней грани скругления.

tf_external 

По внешней грани скругления.

tf_average 

По среднему значению.

◆ MedianAttr

enum MedianShellValues::MedianAttr

Флаг расчета и записи в атрибуты грани значения толщины срединной оболочки.

Флаг можно установить через вызов MedianShellValues::SetMedianAttr().

Элементы перечислений
ma_none 

Не записывать.

ma_min 

Записывать, для граней скругления, создаваемых при filletType !=tf_none, принимать толщину как минимальное значение среди соседних граней.

ma_mid 

Записывать, для граней скругления, создаваемых при filletType !=tf_none, принимать толщину как среднее значение среди соседних граней.

ma_max 

Записывать, для граней скругления, создаваемых при filletType !=tf_none, принимать толщину как максимальное значение среди соседних граней.

◆ InputMode

enum MedianShellValues::InputMode

Вид входных граней.

Уточняет как трактуются заданные пары граней.

Элементы перечислений
im_pairs 

Пары граней.

im_twogroups 

Две группы граней. Первая грань в каждой паре идет в первую группу, вторая - во вторую.
