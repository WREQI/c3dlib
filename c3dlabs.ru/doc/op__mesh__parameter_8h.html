◆ MbeIcpHintUsageMode

enum MbeIcpHintUsageMode
strong

Режим использования подсказки при совмещении объектов по алгоритму ICP.

Режим использования подсказки при совмещении объектов по алгоритму ICP. Режим без использования подсказки подразумевает совмещение объектов в их исходном положении. Другие режимы допускают начальную трансформацию движущегося объекта.

Предупреждения
В разработке.
Элементы перечислений
noHint 

Не использовать подсказку.

autoHint 

Автоопределение подсказки по инерционным характеристикам.

givenHint 

Использовать подсказку, заданную пользователем.

◆ MbeIcpPointRejectionMode

enum MbeIcpPointRejectionMode
strong

Режим отбраковки точек при совмещении объектов по алгоритму ICP.

Предупреждения
В разработке.
Элементы перечислений
noReject 

Не отбраковывать точки.

automatic 

Автоопределение порога для отбраковки.

constant 

Отбраковка заданной доли из общего числа точек.

◆ MbePositionConstraintType

enum MbePositionConstraintType
strong

Тип позиционного ограничения.

Тип позиционного ограничения. Определяет вариант фиксации положения объекта в пространстве. Можно ограничить перемещения вдоль и повороты вокруг координатных осей некоторой локальной системы координат в разных комбинациях.

Предупреждения
В разработке.
Элементы перечислений
z 

Разрешен только сдвиг вдоль оси OZ плейсмента параметров.

w 

Разрешен только поворот вокруг оси OZ плейсмента параметров.

zw 

Разрешен только сдвиг вдоль оси OZ и поворот вокруг оси OZ плейсмента параметров.

xyz 

Разрешен только параллельный перенос (запрещены повороты вокруг координатных осей плейсмента параметров).

xyw 

Разрешен только параллельный перенос вдоль осей OX и OY и поворот вокруг оси OZ плейсмента параметров.

xyzw 

Разрешен параллельный перенос вдоль координатных осей и поворот вокруг оси OZ плейсмента параметров.

uvw 

Разрешен только поворот вокруг координатных осей плейсмента параметров (запрещен любой параллельный перенос).

free 

Без ограничений.

◆ MbeDimensionalConstraintType

enum MbeDimensionalConstraintType
strong

Тип размерного ограничения.

Тип размерного ограничения. Определяет вариант фиксации размеров объекта. Можно зафиксировать радиус сферы, радиус цилиндра, уклон конуса, большой и малый радиусы тора (только один их них или сразу оба).

Предупреждения
В разработке.
Элементы перечислений
none 

Без ограничений.

first 

Зафиксирован только первый размерный параметр объекта.

second 

Зафиксирован только второй размерный параметр объекта (корректно только для тора).

both 

Зафиксированы оба размерных параметра объекта (корректно только для тора).
