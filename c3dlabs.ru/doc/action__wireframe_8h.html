Создать скругленный каркас.

Создать каркас в виде плавного соединения (скругления) всех ребер каркаса.
Если два ребра в каркасе гладко стыкуются, в этом стыке скругление не делается, радиус игнорируется.

Аргументы
[in]wireframe- Исходный каркас.
[in]sameEdges- Режим копирования входного каркаса.
[in]params- Параметры скругления.
[out]result- Скругленный каркас.
Возвращает
Возвращает код результата операции.

Построить NURBS копию каркаса.

Строит проволочный каркас, содержащий NURBS кривые, аппроксимирующие заданный каркас. По возможности, строит точные кривые, возможно, с кратными узлами. Количеством узлов для NURBS определяется в зависимости от кривой.

Аргументы
[in]wireFrame- Исходный каркас.
[in]sameWire- Режим копирования входного каркаса.
[in]params- Параметры скругления.
[out]result- Построенный каркас с NURBS кривыми или nullptr при неуспешном построении.
Возвращает
Возвращает код результата операции.
Предупреждения
В разработке.

Найти проекцию точки на проволочный каркас.

◆ ProjectionWireFrame()

MbResultType ProjectionWireFrame ( const MbProjectionWireFrameParams &  params,
MbProjectionWireFrameResults &  results 
)

Операция построения проекционного проволочного каркаса.

Операция построения проекции набора кривых по нормали или по направлению на тело, набор граней или поверхность.

Аргументы
[in]params- Параметры операции.
[out]results- Результаты операции.
Возвращает
Возвращает код результата операции. Непустой результат возвращается при успешном проецировании хотя бы одной из исходных кривых. Если хотя бы одна кривая не спроецировалась успешно, возвращается статус ошибки (не rt_Success).
