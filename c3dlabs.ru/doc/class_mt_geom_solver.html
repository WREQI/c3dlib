Подробное описание

Геометрический решатель.

Интерфейс геометрического решателя. Клиентское приложение может работать с любым количеством систем ограничений, для каждой из них заводится по одному экземпляру решателя с помощью вызова GCM_CreateSolver.

Перенести геометрический объект системы ограничений в подсистему твврдого тела (сделать подчиненным объектом жесткого кластера).

Аргументы
[in]g- Геометрический объект.
[in]tgtCl- Целевой кластер.
Возвращает
Код результата операции.

Для переноса геометрического объекта в глобальную систему необходимо в качестве целевого кластера указать nullptr. В случае успеха функция возвращает код GCM_RESULT_Ok. Если геометрический объект относится к MtGeomSolver::Ground() или был использован как аргумент при вызове метода MtGeomSolver::CreateCluster, то функция оставляет иерархию системы без изменений и возвращает специальный код GCM_RESULT_ImmovableGeom. Если целевой кластер был использован как аргумент при вызове метода MtGeomSolver::CreateCluster, то функция оставляет иерархию системы без изменений и возвращает специальный код GCM_RESULT_UnacceptableCluster. Если целевой кластер вложен в геометрический объект (в том числе совпадает с ним), то функция оставляет иерархию системы без изменений и возвращает специальный код GCM_RESULT_CyclicMove. При удалении кластера методом MtGeomSolver::RemoveGeom все перенесенные в него геометрические объекты автоматически переносятся в его надкластер, если такой имеется, иначе – в глобальную систему.

Указатель (с автоматическим подсчетом ссылок) на новый экземпляр геометрического решателя.
