Параметры создания фаски для пары соседних сегментов контура (или полилинии).

◆ distAngle

double MbCornerChamferParams::distAngle

(type == true ) Угол между первым сегментом и фаской. (type == false) Расстояние от пересечения фаски со вторым сегментом до узла контура.

Тип создания фаски: true для типа расстояние-угол, false для типа расстояние-расстояние.
