Подробное описание

Параметры точки для создания полилинии.

Часть точек может быть удалена при построении, поэтому вводится старый индекс, который заполняется и используется в модели. Параметрами точки являются координаты точки и радиус скругления в этой точке. При создании заполняются поля m_lineSeg и m_arcSeg. m_lineSeg - это прямолинейный сегмент из этой точки в следующую. Для последней точки и замкнутой ломаной - из последней в первую. m_arcSeg - дуга скругления в данной точке. Если какой-то сегмент был полностью удален или не создан, то его указатель должен быть nullptr. Объектами m_lineSeg и m_arcSeg не владеет, поэтому и не удаляет их. Объекты из полилинии.
