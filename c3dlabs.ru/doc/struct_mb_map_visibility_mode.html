◆ LimitDepthMode

enum MbMapVisibilityMode::LimitDepthMode : uint8
strong

Настройки проецирования объектов по глубине видимости.

При наличии ограничений тип опредяляет видимость следов в зависимости от положения объекта относительно границы (глубины) видимости.

Предупреждения
В разработке.
Элементы перечислений
off 

Ограничения по глубине видимости отключены.

on 

Ограничения включены, объекты целиком находящиеся за границей видимости не проецируются.

on_exclude 

Ограничения включены, объекты целиком находящиеся за границей видимости и на границе видимости не проецируются.

cut 

Ограничения включены, объекты целиком находящиеся за границей видимости не проецируются, находящиеся на границе видимости будут проецироваться в рассеченном виде.
