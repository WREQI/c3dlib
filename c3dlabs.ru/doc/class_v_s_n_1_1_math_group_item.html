Подробное описание

Класс MathGroupItem предоставляет элемент для использования с классом MathGroupGeometry.

MathGroupItem представляет отдельный элемент для MathGroupGeometry. Каждый элемент может содержать определенную информацию для его отображения соответствующим образом.
