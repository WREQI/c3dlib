Подробное описание

Параметры заплатки.

Параметры заплатки.
Содержат информацию о типе заплатки и флаге проверки самопересечений. Если задан тип ts_plane, будет построена заплатка плоскими гранями.
Тип ts_byCurves нужно задавать, если требуется построить заплатку с сопряжением по некоторым границам. В этом случае для нужной границы MbPatchCurve нужно задать сопряжение методом #SetMating.
