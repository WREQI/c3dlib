Подробное описание

Свойство. Только для внутреннего использования.

Свойство является базовым классом для доступа к внутренним данным объектов. Наследники свойства могут содержать внутренние данные объектов или их копии. Свойства предназначены для просмотра и модификации внутренних данных объектов.
Для хранения пользовательских данных объекта рекомендуем использовать атрибуты - объекты классов наследующих MbAttribute, уже имеющиеся в ядре или пользовательские.
