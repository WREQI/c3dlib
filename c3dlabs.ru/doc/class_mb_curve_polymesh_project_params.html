Параметры обрезки полигонального объекта набором кривых.

Параметры обрезки полигонального объекта набором кривых.
Сначала кривые линеаризуются с указанной точностью. Далее полученные полилинии проецируются на сетку. Результат проецирования обрабатывается указанным способом.

  1. insert - в сетку врезаются новые ребра;
  2. splitSegmentation - в сетку врезаются новые ребра, по ним производится разбивка сегментации;
  3. keepOuterPart - в сетку врезаются новые ребра, далее удаляется часть сетки внутри контура;
  4. keepInnerPart - в сетку врезаются новые ребра, далее удаляется часть сетки снаружи контура;
  5. insertCheckOpen - в сетку врезаются новые ребра, при этом кривые, оказавшиеся внутри сетки, продлеваются до открытой границы, а выступающие за границу - обрезаются этой границей.
