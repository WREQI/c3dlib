Функции

◆ GCM_FormalDOF()

GCM_dof_estimation GCM_FormalDOF ( GCM_system  gSys,
GCM_geom  g 
)

Оценить снизу и сверху количество формальных степеней свободы геометрического объекта. Определяются минимальным набором линейно независимых параметров, задающих мгновенное движение жесткого тела (в системе ограничений).

Аргументы
[in]gSys- Система ограничений.
[in]g- Дескриптор геометрического объекта.
Возвращает
Количественная оценка (нижняя и верхняя границы с включением) формальных степеней свободы.
Заметки
Для целей тестирования.

Вычислить чистые трансляционные степени свободы геометрического объекта. Такие степени остаются у тела (в системе ограничений) после устранения любых возможностей вращения. Система ограничений.

Аргументы
[in]g- Дескриптор геометрического объекта.
Возвращает
Запись о вычисленных чистых трансляционных степенях свободы.
Заметки
