Метод инициализации параметров элементарного тела для конуса.

Метод инициализации параметров элементарного тела для конуса по плейсменту, радиусам оснований конуса и значению, которое может быть высотой (отрицательной или положительной) или углом при вершине конуса.

Аргументы
[in]place- Плейсмент.
[in]r1- Радиус основания конуса на плоскости XY.
[in]r2- Радиус второго основания конуса, 0 ≤ r2 < r1.
[in]bHeight- Если true, то value - высота, иначе угол.
[in]value- Если bHeight = true, то value = высота (отрицательная или положительная), иначе value = угол при вершине конуса (между двумя противоположными образующими), 0 < угол < Pi.
Возвращает
Возвращает true в случае успеха.

Метод инициализации параметров тела параллелепипеда.

Метод инициализации параметров тела параллелепипеда по плесменту, длине, ширине и высотам.

Аргументы
[in]place- Плейсмент.
[in]dx- Длина.
[in]dy- Ширина.
[in]h1- Высота параллелепипеда от плоскости XY в направлении оси Z.
[in]h2- Высота параллелепипеда от плоскости XY противоположно оси Z.
[in]pointType- Тип точки, находящейся в центре плейсмента:
  1. Вершина.
  2. Центр ребра направленного по оси X.
  3. Центр нижнего основания.
