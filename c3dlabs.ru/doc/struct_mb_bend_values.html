Подробное описание

Параметры сгиба.

При k = 0.0 внутренняя грань сгиба разгибается без деформаций, при k = 1.0 - внешняя.
Параметр radius равен радиусу внутренней цилиндрической грани сгиба, для конического сгиба не определён.
Угол сгиба angle используется при создании цилиндрических сгибов в операциях "сгиб по ребру" и "сгиб по линии".
Параметр coneAngle равен 0.0 для цилиндрического сгиба и больше 0.0 для конического.
