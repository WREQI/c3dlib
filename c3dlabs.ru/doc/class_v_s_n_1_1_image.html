Подробное описание

Класс Image предоставляет инструменты для загрузки/сохранения разных форматов изображений.

Класс Image обычно содержит несжатые данные изображения и является одним из объектов, которые могут быть загружены в текстуру. Как правило, объект Image используется для загрузки текстуры, когда необходимо выполнить дополнительную обработку изображения до его загрузки или когда вы хотите разбить существующую текстуру. Image имеет ряд полезных функций, а также дает возможность прямого доступа к пикселям битовой карты изображения.
