Подробное описание

Старые параметры прямого редактирования тела.

Параметры прямого редактирования тела содержат тип операции (MbeModifyingType) и её параметры. В зависимости от параметра way возможны следующие действия:

  1. Удаление из тела выбранных граней с окружением (way==dmt_Remove). По-умолчанию грани удаляются вместе с прилегающими скруглениями. Для удаления без прилегающих скруглений выставить флаг removeWithFillets = false.
  2. Создание тела из выбранных граней с окружением (way==dmt_Create).
  3. Перемещение выбранных граней с окружением относительно оставшихся граней тела (way==dmt_Action). Направление и величину перемещения определяет вектор direction.
  4. Замена выбранных граней тела эквидистантными гранями (перемещение по нормали, изменение радиуса) (way==dmt_Offset). Расстояние смещения определяется параметром value или длиной вектора direction.
  5. Изменение радиуса выбранных граней скругления (way==dmt_Fillet). Величина изменения радиуса определяется параметром value или длиной вектора direction.
  6. Замена выбранных граней тела деформируемыми гранями (превращение в NURBS) для редактирования (way==dmt_Supple).
  7. Удаление выбранных граней скругления тела (way==dmt_Purify).
  8. Слияние вершин ребёр и удаление рёбер (way==dmt_Merger).
  9. Замена гладко стыкующихся граней одной гранью (way==dmt_United).
  10. Поворот выбранных граней (way==dmt_Rotate). Угол поворота определяется параметром value, ось поворота определяется точкой origin и направлением direction.
Уст.:
Класс устарел и будет удален в версии 2024. Взамен использовать MbModifiedSolidParams.
