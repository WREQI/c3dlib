double &  d,
double  eps = ANGLE_EPSILON 
) const

Найти ближайшую точку пересечения с линией.

Найти ближайшую точку пересечения с линией. Линия задана своими начальной точкой и направляющим вектором: p(d) = origin + d * direction.

Аргументы
[in]origin- Начальная точка исходной линии.
[in]direction- Направляющий вектор исходной линии.
[out]p- Найденная точка пересечения.
[out]d- Параметр точки пересечения на линии.
[in]eps- Толерантность, при которой линия будет считаться параллельной плоскости.
Возвращает
Возвращает true, если пересечение найдено.

Проверить, что вектор ненулевой с заданной точностью.

Проверка ненулевого вектора с заданной точностью. Вектор считается ненулевым, если его координаты превосходят заданную погрешность.

Аргументы
[in]vec- Вектор.
[in]eps- Погрешность координат.
Возвращает
Возвращает true, если вектор ненулевой.
