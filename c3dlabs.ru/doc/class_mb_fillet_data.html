Подробное описание

Данные для построения сопряжения несвязных граней.

Данные для построения гладкого сопряжения двух несвязных (непересекающихся) наборов граней. Каждый набор может состоять только из связных граней одного тела.

Предупреждения
В разработке.
Член класса SmoothValues _params будет удален в версии 2024.

Конструктор по параметрам.

Конструктор данных построения гладкого сопряжения двух несвязных наборов граней.

Аргументы
[in]faces1- Первый набор сопрягаемых граней.
[in]faces2- Второй набор сопрягаемых граней.
[in]faceSplit- Разделять оболочку на грани по сегментам направляющих кривых.
[in]sideShape- Форма обрезки боков поверхности.
[in]function1- Функция радиуса для первого набора граней (всегда не null). Константная функция в случае скругления с постоянным радиусом.
[in]function2- Функция радиуса для второго набора граней (всегда не null). Константная функция в случае скругления с постоянным радиусом.
[in]conic- Коэффициент формы, изменяется от CONIC_MIN_EXT до CONIC_MAX_EXT (при ARC - дуга окружности).
[in]prolong- Продолжить по касательной.
[in]keepCant- Автоопределение сохранения кромки (ts_neutral), сохранение поверхности (ts_negative), сохранение кромки (ts_positive).
[in]equable- В углах сочленения вставлять тороидальную поверхность.
[in]nameMaker- Именователь новых граней операции.
