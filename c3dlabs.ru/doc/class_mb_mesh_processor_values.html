Данные класса

◆ useRelativeTolerance

bool MbMeshProcessorValues::useRelativeTolerance

Использовать относительную точность (true).

При использовании относительной точности отклонение граней тела от сетки проверяется относительно размера модели.

◆ smoothBoundaryEdges

bool MbMeshProcessorValues::smoothBoundaryEdges

Флаг сглаживания краевых ребер.

Сглаживать краевые ребра результирующей оболочки или строить их кусочно-линейными.

◆ bAngle

double MbMeshProcessorValues::bAngle

Предельное значение угла между соседними внешними ребрами сетки в радианах.

Предельное значение угла между соседними ребрами сетки используется при построении граничных ребер оболочки: граничные ребра оболочки будут разделяться в вершинах, где наименьший угол между соседними внешними ребрами сетки менее данного предельного.

◆ tolerance

double MbMeshProcessorValues::tolerance

Точность.

Точность работы метода: допустимое отклонение граней тела от вершин сетки.
