Подробное описание

Параметры операции расчета кривизн полигональной сетки.

Параметры операции расчета кривизн полигональной сетки. Возможны два метода - с помощью дискретного дифференциального оператора, и с помощью вписывания полиномиальной поверхности в окрестность вершины. Количество соседей для второго метода должно быть в пределах от 1 до 10.
