Подробное описание

Кривая в двумерном пространстве, заданная точками.

Родительский класс кривых в двумерном пространстве, заданных контрольными точками: MbBezier, MbCubicSpline, MbHermit, MbNurbs, MbPolyline.

◆ IsClosed()

bool MbPolyCurve::IsClosed ( ) const
overridevirtual

Определить, является ли кривая периодической.

Определить, является ли кривая периодической.
Периодическая кривая является замкнутой. Кривая считается периодической, если:

  • начальная и конечная точка кривой совпадают;
  • производные в начальной и конечной точке совпадают;
    если по своей природе кривая допускает изломы (контур, ломаная), то допускается не совпадение производных; у кривой Безье производные должны совпадать по направлению, но могут не совпадать по модулю.
    Кривые:
  • MbLine,
  • MbLineSegment,
  • MbCosinusoid,
  • MbContour (если он содержит только один сегмент одного из указанных типов)
    не считаются периодическими при совпадении начальной и конечной точек. Метод IsClosed() для них всегда возвращает false.
Возвращает
true, если кривая замкнута.

Замещает MbCurve.
