Класс VSN::ExplodeParameterValues

Класс ExplodeParameterValues используется для получения набора данных диапазонного типа, определяемых управляющим параметром. Для получения данных используется метод ExplodeDispatcher::GetParameterValues(). Если для запрашиваемого параметра такой диапазонный тип не поддерживается, метод ExplodeDispatcher::GetParameterValues() вернет значение ResultState::rs_UnSupported. Подробнее...
