enum CDM_result

Код результата контроля столкновений или измерений.

Элементы перечислений
CDM_RESULT_MeasuringSucceed 

Успешный результат измерительного запроса (например, запрос на минимальное расстояние).

CDM_RESULT_NoCollisionDetected 

Столкновний не выявлено. Пересечений нет или поиск был прерван.

CDM_RESULT_CollisionDetected 

Выявлено хотя бы одно объемное пересечение (коллизия).

CDM_RESULT_Error 

Неизвестная ошибка или внутрисистемная ошибка.

Расчет пересечений тел посредством аппарата булевой операции.

Расчет пересечений тел посредством аппарата булевой операции.

Аргументы
[in]solid1- Первое тело.
[in]solid2- Второе тело.
[out]edges- Ребра пересечения тел.
[out]intersectedFaces- Пары номеров пересекшихся граней.
  • Пары номеров касающихся граней с противоположно направленными нормалями.
[out]similarFaces- Пары номеров касающихся подобных граней, которые могут быть объединены.
Возвращает
Код результата операции.
Предупреждения
Тела будут изменены операцией! Если требуется сохранить тела без изменений, передавайте копии, сделанные помощью MbSolid::Duplicate().

◆ CDM_AddInstance() [1/2]

cdet_item CDM_AddInstance ( cdet_scene  scn,
const CDM_instance &  inst 
)

Добавить экземпляр тела с заданным положением в сцену для детектора столкновений.

Аргументы
[in]inst- Запись экземпляра геометрического объекта (полигональное или граничное представление).
Возвращает
Дескриптор объекта для детектора столкновений.
Повторно-используемые элементы сцены

Один и тот же экземпляр класса 'MbItem' может быть добавлен в сцену сколько угодно раз с помощью данного вызова. При многократном добавлении одного и того же геометрического объекта детектор столкновений создает только одну поисковую структуру данных (BVT). Ресурсы памяти и времени вычислений, потраченные на создание такой структуры, повторно используется для всех экземпляров сцены, основанные на одном и том же объекте 'MbItem'.

◆ CDM_CheckCollisions() [1/2]

cdet_result CDM_CheckCollisions ( cdet_scene  scn,
cdet_query &  cdQuery 
)

Запросить поиск столкновений между элементами сцены.

Возвращает
Коды результата детектора столкновений и измерение расстояния.

Осуществляется поиск столкновения между элементами сцены согласно запроса cdQuery, а именно проверяются пары, как на уровне сборки, включая компоненты целиком, так и на уровне отдельных компонент. Клиентское приложение имеет возможность настроить запрос так, чтобы искать столкновения не всех со всеми, а только между группами объектов.
