Подробное описание

Интерфейс конвертера.

Интерфейс конвертера реализует методы экспорта модели в файлы обменных форматов и импорта из них.

Методы

◆ SetConfgiurationSelector()

virtual DEPRECATE_DECLARE void IConverter3D::SetConfgiurationSelector ( SPtr< IConfigurationSelector >  configuration_selector)
pure virtual

Установить обработчик для выбора конфигураций.

Уст.:
Метод устарел, вместо него необходимо использовать SetConfigurationSelector().

Если обработчик установлен и в импортируемом файле есть более одной конфигурации (исполнения), то в процессе чтения будет вызван установленный обработчик для выбора необходимой конфигурации.

Аргументы
[in]configuration_selector- Указатель на устанавливаемый обработчик.
