Перечисления

◆ ProjProcessingMethod

enum ProjProcessingMethod : uint
strong

Перечисление для способа обработки результатов проецирования и других операций.

Элементы перечислений
insert 

Просто врезать в сетку.

splitSegmentation 

Разбить сегментацию.

keepOuterPart 

Оставить в сетке только внешнюю часть контура.

keepInnerPart 

Оставить в сетке только внутреннюю часть контура.

insertCheckOpen 

Врезать в сетку с контролем открытых границ.
