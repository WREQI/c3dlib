Аргументы

[in]srcVCnt- Количество разбиений базовой поверхности по V.
[in]dstSurface- Целевая поверхность.
[in]ver- Версия операции.

Конструктор по параметрам.

Конструктор параметров операции для измерения экстремальных расстояний между кривыми. Режим проецирования - либо по нормали к целевой кривой, либо в плоскости, перпендикулярной касательной базовой кривой.

Аргументы
[in]srcSurface- Базовая кривая.
[in]srcTCnt- Количество разбиений базовой кривой.
[in]useEqualDists- Оставлять равные расстояния.
[in]byNormal- byNormal = true задает режим проецирования по нормали к целевой кривой.
[in]dstCurve- Целевая кривая.
[in]nMin- Желаемое число выдаваемых минимумов.
[in]nMax- Желаемое число выдаваемых максимумов.
[in]ver- Версия операции.
