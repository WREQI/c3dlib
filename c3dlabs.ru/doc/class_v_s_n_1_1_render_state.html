Подробное описание

Состояние отрисовки объекта. Класс RenderState хранит состояние отрисовки и предоставляет функции для управления режимами отрисовки объектов RenderObject.

Методы

◆ GetProperRenderingState()

RenderingState VSN::RenderState::GetProperRenderingState ( ) const

Вернуть собственное состояние отрисовки.

Функция возвращает собственное состояние отрисовки, присущее данному объекту вне зависимости от его временных состояний, таких как режим подсветки или выбор.

◆ GetPolyFaceMode()

DrawBufferMode VSN::RenderState::GetPolyFaceMode ( ) const

Вернуть значение режима отрисовки для граней.

Возвращает
Одно из следующих значений отрисовки: GL_FRONT_AND_BACK, GL_FRONT или GL_BACK.

Установить режим отображения для граней и полигонов.

Аргументы
[in]fMode- Режим отрисовки для граней с одним из следующих значений: GL_FRONT_AND_BACK, GL_FRONT, and GL_BACK.
[in]pMode- Режим отрисовки для кривых с одним из следующих значений: GL_POINT, GL_LINE, or GL_FILL.
