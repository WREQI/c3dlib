const MbCartPoint3D &  point2,
MbeSpaceType  surfaceType,
MbSurface *&  result 
)

Создать элементарную поверхность.

Создать одну из элементарных поверхностей по трем управляющим точкам и типу:
surfaceType == st_Plane - плоскость
surfaceType == st_ConeSurface - коническая поверхность
surfaceType == st_CylinderSurface - цилиндрическая поверхность
surfaceType == st_SphereSurface - сферическая поверхность
surfaceType == st_TorusSurface - поверхность тора

Аргументы
[in]point0- Точка, определяющая начало локальной системы координат поверхности.
[in]point1- Точка, определяющая направление оси X локальной системы и радиус поверхности.
[in]point2- Точка, определяющая направление оси Y локальной системы.
[in]surfaceType- Тип поверхности.
[out]result- Построенная поверхность.
Возвращает
Возвращает код результата операции.

Построение поверхности переменного сечения.

Поверхность переменного (конического) сечения образуется путем движения плоской кривой, являющейся коническим сечением, вдоль опорной кривой. В процессе движения форма плоской кривой меняется в соответствии с дискриминантом конического сечения. Начало плоской кривой располагается на начальной направляющей кривой, а конец - на конечной направляющей кривой. Плоскость переменного сечения сохраняет ортогональность опорной кривой в процессе движения.

Аргументы
[in]rc- Опорная кривая.
[in]g1- Первая направляющая кривая.
[in]g2- Вторая направляющая кривая (g1==g2 совпадает с первой при cs_Round).
[in]c0- Дополнительная направляющая кривая (может быть nullptr).
[in]form- Форма сечения поверхности (0, 1, 2, 3).
[in]sense- Направление нормали поверхности направляющей кривой (для guide1==guide2).
[in]uBeg- Минимальное значение первого параметра поверхности.
[in]uEnd- Максимальное значение первого параметра поверхности.
[in]func- Функция управления сечением поверхности.
[in]patt- Образующая кривая при form==cs_Shape.
[in]accuracy- Точность построения.
[in]vers- Версия поверхности.
[out]result- Построенная поверхность.
Возвращает
Возвращает код результата операции.
Предупреждения
В разработке.
