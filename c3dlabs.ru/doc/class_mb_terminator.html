static

Создать терминатор.

Аргументы
[in]location- Расположение терминатора в плоскости отображения,
[in]type- Тип терминатора,
[in]sizeX- Размер терминатора по координате x расположения,
[in]sizeY- Размер терминатора по координате y расположения.
Возвращает
Экземпляр терминатора, если строка типа не пуста и размеры больше Math::lengthEpsilon, иначе нулевой указатель.
