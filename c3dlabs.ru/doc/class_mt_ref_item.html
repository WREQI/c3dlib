Заметки
It is used as an ancestor class for ATS-interfaces.
Внимание

Данный класс имеет консервативную реализацию подсчета ссылок, т.е. требует особых мер для работы в многопоточном режиме. Другой класс с аналогичными функциями MbRefItem предусматривает обращение из разных потоков.
