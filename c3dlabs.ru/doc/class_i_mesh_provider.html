MbPolymeshTopo &  polymesh 
) const
virtual

Установить атрибуты топологии.

Предполагается, что объект polymesh содержит аттрибут маппинга от ребер сетки к порядковому номеру вершины на грани MbHalfedgeAttrSizetEdge и атрибут для пометок перевернутых в процессе алгоритма фасетов MbHalfedgeAttrBoolFacet. Среди всех атрибутов данная функция устанавливает только атрибуты нормалей вида MbHalfedgeAttrNormalsVertex. Для установки других атрибутов следует создать наследника этого класса. Флаг усреднения нормалей по веерам объединенных вершин.

Аргументы
[in,out]polymesh- Полигональный геометрический объект.
