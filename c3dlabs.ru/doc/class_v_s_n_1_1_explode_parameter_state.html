Класс VSN::ExplodeParameterState

Класс ExplodeParameterState используется для получения состояния элементов управления GUI по управляющему параметру. Для получения состояния используется метод ExplodeDispatcher::GetParameterState(). Если для запрашиваемого параметра наличие состояния не поддерживается, метод ExplodeDispatcher::GetParameterState() вернет значение ResultState::rs_UnSupported. Подробнее...
