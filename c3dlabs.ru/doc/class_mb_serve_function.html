Подробное описание

Монотонно возрастающая служебная функция v(t) = a * t * t + b * t + c.

Функция служит для изменения параметризации кривых, обеспечивающей непрерывномть производных составных кривых.

Репараметризация, обеспечивающая на концах новой кривой указаные производные параметра.
