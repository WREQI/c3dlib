◆ GCM_CreateSolver()

SPtr<MtGeomSolver> GCM_CreateSolver ( SPtr< ItPositionManager >  pMan)

Создать объектно-ориентированный интерфейс 3D солвера.

Аргументы
[in]pMan- Интерфейс, предоставляющий функции репозиции геометрических объектов на стороне приложения.

Вызов создает пустую систему ограничений. Кроме того, в памяти создаются внутренние структуры данных геометрического решателя, обслуживающего систему ограничений. Функция возвращает экземпляр класса, представляющего объектно-ориентированный интерфейс солвера.

Возвращает
Указатель (с автоматическим подсчетом ссылок) на новый экземпляр геометрического решателя.
