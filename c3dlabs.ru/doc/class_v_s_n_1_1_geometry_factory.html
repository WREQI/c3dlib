Подробное описание

Класс GeometryFactory представляет фабрику представлений геометрических объектов, а также генерацию готовой сцены для последующей отрисовки.

GeometryFactory имеет две группы функций. Первая группа работает непосредственно с математическими объектами и тем самым обеспечивает глубокую интеграцию с математическим ядром. Вторая группа генерирует представления простых объектов, таких как куб, цилиндр, сфера и др., т.е. где полигональная модель рассчитывается не с помощью математического ядра, а самими визуальными объектами.
