Подробное описание

Индекс идентификации объекта.

Индекс содержит имя, номер в теле и контрольную точку и служит для поиска объекта (грани, ребра, вершины) в оболочке. Поиск объекта производится по имени, в случае неудачи - по номеру, и проверяется по контрольной точке.
