Подробное описание

Глобальные настройки для модуля визуализации.

Класс GlobalFlags предоставляет функции для управления общими настройками модуля визуализации C3D Vision.

Методы

◆ IsScenePixelCullingEnabled()

static bool VSN::GlobalFlags::IsScenePixelCullingEnabled ( )
static

Вернуть true, если используется pixel culling при управлении сценой.

По умолчанию флаг установлен в значение false. При активации процесса PrCameraOrbit, PrCameraPan или другого процесса управления сценой этот флаг устанавливается автоматически в значение true, при деактивации процесса восстанавливает старое значение.

Заметки
Если необходимо, чтобы функция PixelCulling работала все время нужно вручную установить значение флагов scenePixelCullingEnabled и pixelCullingEnabled в true.
