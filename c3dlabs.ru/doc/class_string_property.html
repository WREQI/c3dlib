Подробное описание

string свойство.

string свойство предназначено для просмотра и модификации данных типа TCHAR *.

Конструктор по параметрам.

Конструктор по параметрам. Максимальная длина строки ограничена 128 символами. Если длина строки инициализации больше, то строка-значение обрезается.

Аргументы
[in]name- Номер подсказки.
[in]initValue- Строка инициализации.
[in]change- Признак редактируемости.
