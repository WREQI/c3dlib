Подробное описание

Класс Fields определяет четыре поля прямоугольника.

Fields определяет набор из четырех полей: левый, верхний, правый и нижний, которые описывают размеры границ, окружающих прямоугольник. Функция IsNull() возвращает значение True, только если все поля равны нулю.
