Конструктор по умолчанию.

Конструктор параметров выдавливания для построения замкнутой оболочки без тонкой стенки в прямом направлении на величину, равную 10.0.

Конструктор по глубинам выдавливания.

Конструктор параметров выдавливания для построения замкнутой оболочки без тонкой стенки. Способ построение в обоих направлениях - на заданную глубину.

Аргументы
[in]scalarValue1- Глубина выдавливания в прямом направлении.
[in]scalarValue2- Глубина выдавливания в обратном направлении.
