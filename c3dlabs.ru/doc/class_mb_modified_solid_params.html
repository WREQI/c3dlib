Подробное описание

Параметры прямого редактирования тела.

Параметры прямого редактирования тела содержат тип операции (MbeModifyingMode) и её параметры. В зависимости от параметра _modificationType возможны следующие действия:

  1. Удаление из тела выбранных граней без прилегающих скруглений dmm_RemoveFaces.
    Для удаления грани вместе с прилегающими скруглениями dmm_RemoveFacesWithAdjacentFillets.
    Удаление замкнутых цилиндрических, сферических граней, граней вращения и выдавливания радиуса меньше заданного без прилегающих скруглений dmm_RemoveBelowRadius.
    Удаление замкнутых цилиндрических, сферических граней, граней вращения и выдавливания радиуса меньше заданного вместе с прилегающими скруглениями dmm_RemoveBelowRadiusWithAdjacentFillets.
  2. Создание тела из выбранных граней с окружением dmm_Create.
  3. Перемещение выбранных граней с окружением относительно оставшихся граней тела dmm_MoveFacesByVector или dmm_MoveFacesByVectorNoAdaptation без адаптации скруглений. Направление и величину перемещения определяет вектор direction.
  4. Замена выбранных граней тела эквидистантными гранями (перемещение по нормали, изменение радиуса) dmm_OffsetFaces. Расстояние смещения определяется параметром value.
  5. Изменение радиуса выбранных граней скругления на заданную величину dmm_FilletsRadiusChange. Величина изменения радиуса определяется параметром value.
  6. Замена выбранных граней тела деформируемыми гранями (превращение в NURBS) для редактирования dmm_ConvertFacesToNurbs.
  7. Удаление выбранных граней скругления тела dmm_PurifyFillets. Для удаления также всех гладко прилегающих скруглений _modificationType==dmm_PurifyFilletsChains. Для удаления всех скруглений тела, меньших определённого радиуса _modificationType==dmm_PurifyFilletsBelowRadius.
  8. Слияние вершин ребёр и удаление рёбер dmm_DeleteEdges.
  9. Замена гладко стыкующихся граней одной гранью dmm_UniteFaces.
  10. Поворот выбранных граней dmm_RotateFaces с адаптацией прилегающих скруглений или dmm_RotateFacesNoFilletAdaptation без адаптации. Угол поворота определяется параметром angle, ось поворота определяется осью axis.
  11. Замена выбранных граней тела dmm_ReplaceFaces.
  12. Установить радиус цилиндрических граней dmm_CylinderRadiusSet с адаптацией прилегающих скруглений или dmm_CylinderRadiusSetNoAdaptation без адаптации. Новый радиус граней определяется параметром value.
  13. Установить радиус сферических граней dmm_SphereRadiusSet с адаптацией прилегающих скруглений или dmm_dmm_SphereRadiusSetNoAdaptation без адаптации. Новый радиус граней определяется параметром value.

Построить модифицированную оболочку.

Построить оболочку тела путём модификации исходной оболочки. В зависимости от параметров модификации ModifyValues метод выполняет одно из следующих действий:

  1. Удаление из тела выбранных граней с окружением (param.way==dmt_Remove).
  2. Создание тела из выбранных граней с окружением (param.way==dmt_Create).
  3. Перемещение выбранных граней с окружением относительно оставшихся граней тела (param.way==dmt_Action).
  4. Замена выбранных граней тела эквидистантными гранями (перемещение по нормали, изменение радиуса) (param.way==dmt_Offset).
  5. Изменение радиуса выбранных граней скругления (param.way==dmt_Fillet).
  6. Замена выбранных граней тела деформируемыми гранями (превращение в NURBS) для редактирования (param.way==dmt_Supple).
  7. Удаление выбранных граней скругления тела (param.way==dmt_Purify).
  8. Слияние вершин ребёр и удаление рёбер (param.way==dmt_Merger).
  9. Замена гладко стыкующихся граней одной гранью (param.way==dmt_United).
  10. Поворот выбранных граней (param.way==dmt_Rotate).
    Одновременно с построением оболочки функция создаёт её строитель.
    Уст.:
    Метод устарел и будет удален в версии 2024.
    Аргументы
    [in]outer- Исходная оболочка.
    [in]sameShell- Режим копирования исходной оболочки.
    [in]parameters- Параметры модификации.
    [in]faces- Изменяемые грани тела.
    [in]edges- Изменяемые рёроа тела.
    [in]names- Именователь операции.
    [out]res- Код результата операции выдавливания.
    [out]shell- Построенная оболочка.

    Возвращает строитель оболочки.
