Подробное описание

Структура для передачи ребра и функции или опорной кривой.

Структура передаёт информацию о ребре и функции изменения радиуса скругления ребра или об опорной кривой для скругления. Структура используется в алгоритмах скругления ребер переменным радиусом.
Начальный параметр функции изменения радиуса соответствует начальной вершине ребра. Конечный параметр функции изменения радиуса соответствует конечной вершине ребра.
