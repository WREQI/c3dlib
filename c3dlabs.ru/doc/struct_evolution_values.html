Параметры кинематической операции.

Параметры операции движения образующей по направляющей кривой.

Конструктор по умолчанию.

Конструктор параметров кинематической операции для построения замкнутой оболочки без тонкой стенки с сохранением угла наклона.

Данные класса

◆ mode

int EvolutionValues::mode
protected

Способ переноса образующего контура вдоль направляющей.

Способ переноса образующего контура вдоль направляющей:
mode <= 0 - Образующая переносится параллельно самой себе;
mode == 1 - Образующая при переносе сохраняет исходный угол с направляющей;
mode == 2 - Плоскость образующей выставляется и сохраняется ортогональной направляющей.
mode > 3 - Образующая переносится согласованно с нормалью к поверхности.
