bool VariableSectionValues::AddConstraintFunction ( const MbFunction *  func)

Добавить функцию ограничения, наложенного на образующие контуры.

Добавить функцию ограничения, наложенного на образующие контуры. Область определения функции должна быть [0, 1]. Значение параметра интерпретируется как часть метрической длины части траектории, соответствующей области определения элемента.

Аргументы
[in]func- Функция ограничения, наложенного на образующие контуры.
Возвращает
true, если функция была добавлена.
