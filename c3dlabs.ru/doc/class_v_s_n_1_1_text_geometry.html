Подробное описание

Класс TextGeometry предназначен для отображения текста на основе заданного шрифта.

В плоскости экрана.

В плоскости размера с доворотом по вектору взгляда.

float  y 
)

Устанавливает привязку текста \detail Устанавливает относительное позиционирование базовой точки относительно текста. По умолчанию это точка (0,0) - левый нижний угол текста. Точка (1, 1) будет соответствовать правому верхнему углу текста.

Аргументы

[in]yПозиция привязки в направлении оси Y.
