◆ GetMetadataWritePath()

c3d::path_string C3dModelDocument::GetMetadataWritePath ( )
overridevirtual

Получить путь для записи метаданных.

Метаданные используются в тех случаях, когда не вписываются не в геометрическую, ни в атрибутивную модели. Этот метод является альтернативным для GetMetadataReceiver(), для случаев, когда для приложения предпочтительнее записывать метаданные в файловую систему вместо передачи через IConverterMetadataReceiver. Указанный каталог должен существовать, быть пустым и доступным для записи.

Возвращает
Путь для записи метаданных в файловую систему.

Переопределяет метод предка ItModelDocument.
