Класс VSN::Font

Класс Font описывает шрифт для отрисовки текста.\detail Класс Font описывает шрифт для отрисовки текста. Позволяет менять такие параметры шрифта как семейство, курсивность и жирность. Когда мы устанавливаем новый параметр шрифта, происходит поиск шрифта в базе с соответствующими параметрами, и, в случае успеха, шрифт меняется на новый. Семейство шрифта может быть задано как точным названием (например, 'Times New Roman'), так и сокращенным (например, 'times'). Регистр букв значения не имеет. Если шрифт не находится в базе, то используется шрифт по умолчанию. Для работы с базой шрифтов используйте класс FontDatabase. Подробнее...

Подробное описание

Класс Font описывает шрифт для отрисовки текста.

\detail Класс Font описывает шрифт для отрисовки текста. Позволяет менять такие параметры шрифта как семейство, курсивность и жирность. Когда мы устанавливаем новый параметр шрифта, происходит поиск шрифта в базе с соответствующими параметрами, и, в случае успеха, шрифт меняется на новый. Семейство шрифта может быть задано как точным названием (например, 'Times New Roman'), так и сокращенным (например, 'times'). Регистр букв значения не имеет. Если шрифт не находится в базе, то используется шрифт по умолчанию. Для работы с базой шрифтов используйте класс FontDatabase.
