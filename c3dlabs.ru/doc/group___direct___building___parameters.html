◆ MbeModifyingType

enum MbeModifyingType

Старые типы модификации.

Тип определяет действия при прямом моделировании.

Элементы перечислений
dmt_Remove 

Удаление из тела выбранных граней с окружением.

dmt_Create 

Создание тела из выбранных граней с окружением.

dmt_Action 

Перемещение выбранных граней с окружением относительно оставшихся граней тела.

dmt_Offset 

Замена выбранных граней тела эквидистантными гранями (перемещение по нормали, изменение радиуса).

dmt_Fillet 

Изменение радиусов выбранных граней скругления на заданную величину.

dmt_Supple 

Замена выбранных граней тела деформируемыми гранями (превращение в NURBS для редактирования).

dmt_Purify 

Удаление из тела выбранных скруглений.

dmt_Merger 

Слияние вершин ребёр и удаление рёбер.

dmt_United 

Замена гладко стыкующихся граней одной гранью.

dmt_Rotate 

Поворот выбранных граней тела.

dmt_Undefined 

Служебный.

Удаление замкнутых цилиндрических, сферических граней, граней вращения и выдавливания радиуса меньше заданного.

Удаление замкнутых цилиндрических, сферических граней, граней вращения и выдавливания радиуса меньше заданного вместе с прилегающими скруглениями.

dmm_OffsetFaces
