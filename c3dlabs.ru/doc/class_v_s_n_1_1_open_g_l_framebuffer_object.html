Подробное описание

OpenGLFramebufferObject инкапсулирует объект framebuffer OpenGL.

OpenGLFramebufferObject представляет некую поверхность рендренга, на которой можно также и рисовать с помощью вызовов функций OpenGL. Эта поверхность может быть привязана и использована, как обычная текстура в вашем собственном коде для рисования OpenGL. По умолчанию класс OpenGLFramebufferObject генерирует 2D-текстуру OpenGL и использует GL_TEXTURE_2D, которая используется внутри рендринга. При создании OpenGLFramebufferObject
необходимо оперировать флагами depth и stencil, чтобы иметь правильное отображение. Чтобы примитивы отображались сглаженными, необходимо при задании формата OpenGL установить SetSamples.
.

Заметки
При создании объекта OpenGLFramebuffer важно иметь текущий контекст OpenGL, иначе инициализация завершится неудачно.
