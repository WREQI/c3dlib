Подробное описание

Класс SegmentInstance представляет данные сегмента сцены.

Класс SegmentInstance может содержать представление геометрии, а также ссылку на ее. Класс SegmentInstance может имеет контейнер SceneSegment в качестве дополнительной информации о ссылке на представление.
