Подробное описание

Данные для обеспечения дискретной длины/радиуса/расстояния.

Данные для обеспечения дискретной длины/радиуса/расстояния в процессах пользовательского ввода кривых.
Для округления до числа, кратного значению шага курсора:
Стандартное округление - значение округляется в меньшую сторону, если разница между текущим значением и ближайшим кратным меньше половины шага курсора, в противном случае округление выполняется в большую сторону.
