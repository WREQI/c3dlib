Подробное описание

Параметры построения тела из листового материала.

Параметры построения тела из листового материала для операций "Листовое тело", "Пластина", "Отверстие", "Вырез".
Параметр thickness - это толщина листа при выдавливании незамкнутого контура.
Глубина выдавливания задаётся в параметрах side1 или side2, в зависимости от направления выдавливания. Коэффициент нейтрального слоя k нужен для построения листового тела по незамкнутому контуру в разогнутом виде.
Параметр radius - это внутренний радиус цилиндрического сгиба, который формируется в месте негладкой стыковки двух прямолинейных сегментов незамкнутого контура.
