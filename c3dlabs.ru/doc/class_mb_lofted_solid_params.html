Подробное описание

Исходные данные для операции построения тела по сечениям. Исходные данные для операции построения тела по сечениям.
Возможно при этом выполнение Булевой операции над уже имеющимися телами. Поддерживаемые типы Булевой операции:
.

  • bo_Union - объединение,
  • bo_Intersect - пересечение,
  • bo_Difference - вычитание. Значение по умолчанию: bo_Base (никакая операция не делается).

At that, making some Boolean operation with already existing solids is possible. Following types of Boolean operation are supported:

  • bo_Union - union,
  • bo_Intersect - intersection,
  • bo_Difference - subtraction. The default value: bo_Base (no boolean operation will be made).
