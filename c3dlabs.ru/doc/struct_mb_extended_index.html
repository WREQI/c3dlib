Подробное описание

Индекс грани и её ребер.

Индекс грани и её ребер, предназначенных для обработки. Индекс служит для поиска грани и ребра в оболочке. Поиск объекта производится по имени, в случае неудачи - по номеру, и проверяется по контрольной точке.
