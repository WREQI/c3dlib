Подробное описание

Параметры удлинения оболочки.

Параметры удлинения оболочки путём продления грани или достраивания грани.

◆ simplify

bool ExtensionValues::simplify

Построить упрощенную эквидистанту.

Флаг, отвечающий за построение эквидистанты по средствам сдвига кривой по нормали к отрезку, соединяющему ее концы на расстояние distance. При этом, сдвинутая эквидистанта заменяется отрезком, если последний не пересекает габарита исходной кривой.
