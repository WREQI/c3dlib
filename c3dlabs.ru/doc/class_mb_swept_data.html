Подробное описание

Данные об образующей.

Данные об образующей операции движения.
Образующая операции выдавливания, вращения или кинематической операции может включать в себя набор двумерных контуров, набор трехмерных контуров, проволочный каркас, тело.
Для набора двумерных контуров на поверхности существуют следующие ограничения:
– может быть один или несколько контуров;
– если контуров несколько, они должны быть либо все замкнуты, либо все разомкнуты;

  • если контуры замкнуты, они могут быть вложенными друг в друга, уровень вложенности не ограничивается;
    – контуры не должны пересекаться между собой или самопересекаться.
    Для двумерных контуров на не плоской поверхности есть дополнительное ограничение: все контуры должны быть замкнуты.
    Построение операции по двумерным контурам на не плоской поверхности рассчитано на указание пользователем грани тела в качестве образующей. В этом случае данные для образующей можно получить с помощью метода грани MbFace::GetSurfaceCurvesData.
    Ограничения для трехмерных контуров:
    – контуры не должны пересекаться между собой или самопересекаться.

Выдать двумерные контуры с поверхностью, полученные с проволочного каркаса.

Выдать двумерные контуры с поверхностью, полученные с проволочного каркаса. Возможные варианты типов каркасов:

  1. Все кроме MbeWireFrameType::spaceContours - контуры строятся по всем кракасам.
  2. Все кроме MbeWireFrameType::undefined - контуры строятся только по каркасам с типом MbeWireFrameType::planeContours и MbeWireFrameType::surfaceContours. Каркас трактуется как плоские контуры или как поверхностные контуры, в зависимости от заданного типа frameType.
  1. All except MbeWireFrameType::spaceContours - contours are built using all frames.
  2. All except MbeWireFrameType::undefined - contours are built only using frames with the MbeWireFrameType::planeContours and MbeWireFrameType::surfaceContours types. The frame is treated as either plane contours or surface contours, depending on the specified frameType.
    Аргументы
    [out]wireSurfaces- Набор поверхностей.
    [out]wireContours- Наборы двумерных контуров для каждой поверхности.
    [in]version- Версия.
    Возвращает
    Количество поверхностей и наборов контуров.

Выдать трехмерные контуры, полученные с проволочного каркаса.

Выдать трехмерные контуры, полученные с проволочного каркаса. Возможные варианты типов каркасов:

  1. Все каркасы имеют типы MbeWireFrameType::spaceContours или MbeWireFrameType::undefined - строим по всем.
  2. Все кроме MbeWireFrameType::undefined - строим только по MbeWireFrameType::spaceContours.

Possible frame types:

  1. All except MbeWireFrameType::spaceContours - contours are built using all frames.
  2. All except MbeWireFrameType::undefined - contours are built only using frames with the MbeWireFrameType::planeContours and MbeWireFrameType::surfaceContours types.
    Аргументы
    [out]wireContours- Наборы двумерных контуров для каждой поверхности.

    Возвращает
