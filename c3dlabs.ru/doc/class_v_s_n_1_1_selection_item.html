Подробное описание

Класс SelectionItem является определением интерфейса для выбранного элемента.

Это абстрактный базовый класс для элементов выбора, который содержится в списке класса SelectionManager. Определяет набор функций для SelectionManager и операторов для взаимодействия в момент выбора. Используйте этот класс в качестве базового класса, если вы хотите реализовать новые типы классов элементов выбора. Примечание: вы не можете создать экземпляр этого класса, т.к. он содержит чистые виртуальные функции, которые не имеют реализацию.
