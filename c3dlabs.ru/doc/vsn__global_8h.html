◆ VSN_FUNC()

VSN_FUNC ( size_t  )

Получить информацию о версии файла c3dvision.

Функция копирует в указанный буфер строку с информацией о версии файла c3d.

Аргументы
[in]buffer- Указатель на начало буфера.
[in]bufferSize- Размер буфера, в символах.
Возвращает
Возвращает количество скопированных символов, без учета null-символа. Если buffer == c3d_null возвращается необходимый размер буфера без учета null-символа.
