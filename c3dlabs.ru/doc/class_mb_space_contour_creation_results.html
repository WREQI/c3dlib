Контейнер индексов.

Контейнер индексов, указывающий номер контура, в который добавлено i-е ребро исходного MbWireFrame. Если i-е ребро MbWireFrame не вошло в построенный контур, то i-ы элемент контейнера _contourIndexes будет равен SYS_MAX_T. Заполняется по требованию.
