Максимальный тип сопряжения, который может быть задан.

Максимальный тип сопряжения, который может быть задан для данной границы и данной поверхности.

Аргументы
[in]prevCurve- Предыдущая граница заплатки.
[in]nextCurve- Следующая граница заплатки.
[in]matingSurface- Поверхность для сопряжения.
Возвращает
pmt_None - Если нельзя задать сопряжение к данной поверхности для данной границы. pmt_Tangent - Если можно задать сопряжение типа pmt_Tangent. pmt_SmoothG2 - Если можно задать сопряжения типов pmt_Tangent и pmt_SmoothG2.
